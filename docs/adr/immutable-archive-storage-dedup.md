# Decision: preserve history through identical archive storage dedup

Keep every historical original path, compressed-byte SHA, raw gzip payload SHA, inner header, native mode/owner and provenance reference. Reversible hardlink dedup is permitted only for complete identical compressed bytes on the same filesystem and equivalent permission metadata, after a fresh visible-reader audit. Unknown live unreadable processes stop the operation; the two documented privileged service gaps remain explicit rather than converted into a global no-reader assertion.

Filesystem access/modification timestamps are storage metadata. Preserve their original per-path nanoseconds in a full restoration manifest; accepting canonical shared-inode timestamps allows substantial space reduction without removing evidence. An independently restorable copy and utimens operation recovers old per-path metadata before future writes. Hardlink dedup requires immutable archives: future writers must use new paths or explicitly break sharing first.

The actual operation completed579 compatible groups/1479 replacements, retained2058 original paths and59 unchanged reference receipts, and stopped at exhaustion of the exact authorized set. Observed free increased791,142,400B with concurrent workspace interference; the2GiB Source allocation floor was not reached. Upper bounds are planning estimates, never acceptance or gain evidence. Original coverage/source/binary history remains present. Durable original failures and the conservative liveness handling are retained with the full result.

The subsequently released83-file source-run archive had no exact compressed match in that verified oracle set, so it was left unchanged. Root then independently reviewed and authorized retirement of one obsolete source worktree whose exact HEAD and all4,502 committed file bytes remain in the active runtime-review worktree. Keep its branch/Git objects and full original native-mode/restoration manifest, remove only verified archived pyc derivatives, and use normal worktree removal. This is the16th specifically authorized source retirement. After rechecking every survivor hash, actual free reached2,377,510,912B (2.214GiB); the2GiB floor was met and cleanup stopped. The observed global delta includes unrelated workspace allocation. No active source, target, original archive or Git object was removed to reach the threshold.
