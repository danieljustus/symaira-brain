# Scoped YAML repair: local verification for #835

This is a local Skills repair, not independent review, native-matrix acceptance,
PR #813 approval, issue closure or a release decision. The accepted exceptions
remain exactly those in [the value-preservation contract](skills-yaml-value-preservation-835.md).

## Production changes

- Keep the existing Skills-private serde/libyaml event encoder. No emitted-YAML
  postpass, full replacement emitter, global dependency override or output exclusion.
- Port yaml.v3 v3.0.1's string-map ordering before metadata serialization, including
  its Unicode L/Nd classifications, leading zeros and wrapping int64 digit arithmetic.
  `yaml_key_ranges.rs` comes from actual Go 1.26.7 `unicode.IsLetter/IsDigit` and is
  checked by the same executable oracle. It is not an ASCII-only natural sort.
- Format finite floats using the existing Ryu shortest digits and Go's `g/-1`
  layout before scalar emission. Correct nested sequence indentation by the pinned
  Go emitter's sequence-state rule, and permit tabs inside literal blocks only.
- Preserve the frozen loader's numeric marshal/reparse behavior separately from
  strings: genuine `-0.0` and integral decimal floats become integers, while
  scientific scalars retain their float runtime kind. Go and Rust use library scalar
  emission/resolution for this numeric-only step. Leading-LF strings remain lossless.
- Repair vendor lint without suppressions: wrapping pointer offsets become equivalent
  wrapping add/sub operations; cleanup macros still free and reset every field using
  raw-pointer stores. No reset, safety behavior or upstream license is removed.
