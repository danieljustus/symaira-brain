# oracle-freeze (ORACLE-FREEZE-781)

Go-recorded oracle output is replayed from committed, sha256-sealed fixtures. Nothing in `make rust-check`,
`rust-fast`, `test`, `parity-smoke` or `init-differential` needs a Go toolchain, a Go binary or Go sources.

| File | Role |
| --- | --- |
| `registry.json` | Which fixtures exist, which group owns them, how/where they were recorded (`record`, `go_inputs`). |
| `../../migration/evidence/oracle-freeze-781/manifest.json` | sha256 + byte size + provenance per fixture (sealed commit, Go toolchain, platform, Go input blob ids). |
| `freeze.py verify [--group G]` | The gate (`make oracle-freeze-check`). FAILS on a missing, empty, changed or unregistered fixture, or missing provenance. Never skips. |
| `freeze.py seal [--group G]` | Re-seals after a deliberate re-record (Go not needed). |
| `test_freeze.py` | Negative controls for the gate (`make oracle-freeze-selftest`). |
| `require_ran.py` | Fails a test command that passed zero cases. |

## Fixture kinds (`record.kind`)

* `go` / `go-test` – regenerated by a Go generator in `scripts/*-oracle` (`record.py check|record`).
* `script` – recorded by a producer script or a Go test with a pinned revision named in the fixture.
* `copy` – byte copy of a Go-repo test input (`internal/**/testdata`, `scripts/*/fixtures`), taken before the Go
  tree is deleted; `seal` refuses a copy that differs from the source blob at HEAD.
* `none` – hand-authored, no Go involved.

## Re-recording

The Go sources and the Go recorders were removed with the Rust cutover
(2026-11-04), so the fixtures are final. A deliberate re-record runs the
historical recorder from a checkout that predates the removal (the
`sealed_at_commit` and `go_inputs` provenance name the exact revision), copies
the result here and re-seals it with `make oracle-freeze-seal` (no Go needed
for sealing).

Replays that mutate process-wide environment variables run in a child test process
(`rust/symbrain-usage/tests/support/frozen_go_evidence.rs::in_child`).
