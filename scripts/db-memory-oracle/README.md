# db-memory-oracle

Frozen production facts about the embedded memory store's SQLite layer,
generated by importing the production packages
`internal/memory/config` and `internal/memory/db` — never by re-implementing
them. The oracle creates a real store, then reads the schema, the pragmas and
the constraint behaviour back out of SQLite.

```sh
# regenerate (pinned toolchain, from the repository root)
GOTOOLCHAIN=$(awk '$1 == "go" { print "go" $2; exit }' go.mod) \
  CGO_ENABLED=0 go run ./scripts/db-memory-oracle

# verify the tracked fixture still matches the current Go sources
GOTOOLCHAIN=$(awk '$1 == "go" { print "go" $2; exit }' go.mod) \
  CGO_ENABLED=0 go run ./scripts/db-memory-oracle -check
```

Verified: `-check` reports "0 drift" (29 tables, 3 negative cases, 2 ordering
cases) on `f2d18e3d`.

## What the fixture covers

- `schema` — every table and index the production migrator creates, plus the
  full `memories` column set (name, type, NOT NULL, default, primary key).
  Covers the `DB-001` half of "schema migrations and pragmas".
- `lock` — the pragmas the store sets (`journal_mode`, `busy_timeout_ms`,
  `foreign_keys`, `secure_delete`), which is the other `DB-001` half.
- `negative_cases` — `null_created_at_rejected`, `null_updated_at_rejected`,
  `missing_table_rejected`. These are the `DB-002` NULL-timestamp constraints.
- `ordering_cases` — `ordering_ties_by_id_desc`,
  `ordering_distinct_by_created_at_desc`. These are the `DB-002` ordering
  guarantees, including the tie-break.

## Status: fixture only — no Rust consumer yet

`DB-001` and `DB-002` stay non-complete. This directory freezes the Go facts so
the next slice can compare `rust/symbrain-memory` against them instead of
re-deriving 29 tables by hand. Until a Rust test loads
`rust/symbrain-memory/tests/fixtures/db_memory_oracle.json` and asserts against
it, the rows are `fixture-ready`, not green.

Produced by a delegated worker that was cut off before writing the Rust
comparison test, and that wrote into the shared checkout instead of its own
worktree; the artifacts were moved here and verified by hand.
