# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

**Do not open a public issue.** Instead, report vulnerabilities privately:

1. Use GitHub's [Private Vulnerability Reporting](https://github.com/danieljustus/symaira-guard/security/advisories/new)
2. Or email security@symaira.com

We aim to respond within 48 hours and publish advisories after a fix is released.
